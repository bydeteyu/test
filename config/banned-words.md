# 금지어 및 금지 표현 목록

## 효능 단정 표현 (절대 금지)

| 금지 표현 | 대체 표현 |
|-----------|-----------|
| 혈당이 잡힌다 | 혈당 관리에 도움 / 혈당 변화 궁금 |
| 혈압이 떨어진다 | 혈압 변화가 궁금하다 / 관리해보신 분 |
| 콜레스테롤이 내려간다 | LDL 수치 변화 궁금 |
| 당뇨가 낫는다 | 혈당 수치 안정 / 경계 수치 관리 |
| 혈압약 끊었다 | 자연으로 관리 시도 / 약 줄여보신 분 |
| 완치됐다 | (절대 사용 불가) |
| 치료된다 | (절대 사용 불가) |
| 효과가 있다 (단정) | 효과 있으셨나요? / 변화 느끼신 분? |

## 의학적 진단·치료 단정 표현 (절대 금지)

- "당뇨입니다", "고혈압입니다" (진단 단정)
- "이 증상은 당뇨 전조입니다"
- "이걸 먹으면 치료됩니다"
- "의사보다 효과적입니다"
- "약 대신 이걸 쓰세요" (명령형)

## 광고 시그널 강도 기준 (0-10점, 낮을수록 좋음)

| 점수 | 기준 | 채택 여부 |
|------|------|-----------|
| 0-3 | 순수 정보·공감형, 제품 노출 없음 | ✅ 채택 |
| 4-5 | 약한 상업적 의도 감지 가능 | ⚠️ 검토 후 결정 |
| 6-7 | 광고임이 눈에 띔 | ❌ 제목 재작성 |
| 8-10 | 노골적 광고 | ❌ 즉시 폐기 |

### 광고 시그널 올리는 요소 (+점)
- 브랜드명 직접 언급: +5
- "구매", "주문", "링크" 포함: +4
- "추천합니다" 단정: +3
- 효능 단정 표현: +3
- 가격·할인 언급: +4

### 광고 시그널 낮추는 요소 (-점)
- 질문형 마무리("?", "ㅠㅠ", ";;"): -1
- 개인 경험담 형식: -1
- 구체 수치 포함: -1
- 가족/지인 이야기 형식: -1
