# 키워드 리서치 보드

바이럴 마케팅 키워드 리서치를 클라이언트별로 관리하는 팀 워크플로우 보드입니다. 클라이언트 인테이크(업종·목표·타겟·우선 채널·금지어)와 키워드 리서치·평가·채택 여부를 한 곳에서 관리합니다.

## 로컬 실행

```
npm install
npm start
```

`http://localhost:3000` 에서 확인할 수 있습니다.

## 구조

- `server.js` — Express 서버. `/api/projects`, `/api/keywords` REST API와 정적 파일(`public/`)을 제공합니다.
- `public/index.html` — 프로젝트 탭, 인테이크 카드, 키워드 리서치 테이블로 구성된 단일 페이지 UI.
- 데이터는 `DATA_DIR`(기본값 `./data`) 아래 `db.json` 파일에 저장됩니다. 서버 재시작 후에도 파일이 남아 있으면 데이터가 유지되지만, 배포 환경에 영구 볼륨이 연결되어 있지 않으면 재배포 시 초기화될 수 있습니다.

## 평가 기준

키워드 평가 점수는 검색량/버즈량 30%, 경쟁강도 20%(낮을수록 유리), 트렌드지속성 20%, 브랜드적합성 20%, 확산가능성 10%의 가중 합산으로 계산되며, 70점 이상이면 자동으로 "채택"으로 표시됩니다.

## 배포

Railway 등 Node.js를 지원하는 플랫폼에 배포할 수 있습니다. `npm start`로 서버가 실행되고, `PORT` 환경 변수를 사용합니다. 데이터를 재배포 후에도 유지하려면 `DATA_DIR`이 가리키는 경로에 영구 볼륨을 연결하세요.
