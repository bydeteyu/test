# 김비서 — 일일 바이럴 키워드·제목 자동 생산 시스템

건강기능식품(컬리케일·써큐톡스) 카페/블로그 바이럴용 제목을 매일 자동 생산하는 시스템입니다.

---

## 디렉토리 구조

```
├── config/
│   ├── products.md        # 제품 정보 및 월별 타깃 스케줄
│   ├── personas.md        # 타깃 페르소나 A/B/C 정의
│   ├── triggers.md        # 키워드 카테고리 6종 + 제목 패턴 A-F
│   └── banned-words.md    # 금지어, 광고 시그널 강도 기준
├── archive/
│   ├── published-titles.md  # 발행된 제목 누적 아카이브
│   └── used-keywords.md     # 최근 30일 사용 키워드 기록
├── output/
│   └── YYYY-MM-DD.md      # 일일 리포트 (자동 생성)
└── README.md
```

---

## 실행 방법

Claude에게 아래 프롬프트를 붙여넣어 실행하세요:

```
김비서 역할로 오늘 일일 바이럴 키워드·제목 자동 생산을 실행해줘.
config/, archive/ 파일을 모두 읽고 Step 1~7을 순서대로 수행한 뒤
output/오늘날짜.md 파일을 생성하고 archive 파일을 업데이트해줘.
```

---

## 준수 원칙

- 제품명(컬리케일, 써큐톡스) 제목 직접 언급 **금지**
- "혈당이 잡힌다", "혈압이 떨어진다" 효능 단정 **금지**
- 광고 시그널 강도 **3점 이하**만 채택
- 이전 발행 제목과 **50% 이상 유사 시** 재작성
- 자세한 기준은 `config/banned-words.md` 참조

## 제품별 타깃 요약

| 제품 | 타깃 증상 | 주요 페르소나 |
|------|-----------|---------------|
| 컬리케일 | 혈당 스파이크, 식후 졸림, 공복혈당 경계 | A (40-50대 여성), C (30-40대 여성) |
| 써큐톡스 | 혈압 경계, 콜레스테롤, 스타틴 부작용 | B (50-60대 남성), A (40-50대 여성) |
