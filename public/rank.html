순위 체크

키워드로 검색했을 때 지정한 콘텐츠가 통합·카페 검색 결과에서 각각 몇 위인지 매일 확인합니다. (← 키워드 리서치 보드)

영구 저장소(Volume)가 연결되지 않았습니다.
지금 상태에서는 서버를 재배포할 때마다 프로젝트·순위 기록이 모두 초기화됩니다. Railway에서 이 서비스에 Volume을 추가하세요. 그 전에는 아래 "데이터 백업"에서 파일을 내려받아 두세요.
네이버 API 키가 설정되지 않았습니다.
서버 환경 변수 NAVER_CLIENT_ID, NAVER_CLIENT_SECRET을 설정해야 순위를 확인할 수 있습니다. (네이버 개발자센터 → 애플리케이션 등록 → 검색 API)

프로젝트

아래의 키워드 검색 · 추적 콘텐츠 · 순위표는 선택한 프로젝트별로 따로 관리됩니다.

키워드로 순위 검색

검색 결과 · 기록

초록색 행은 아래에 등록한 추적 콘텐츠입니다. 검색한 키워드는 매일 자동으로 다시 기록됩니다.

추적할 콘텐츠 추가

제목 문구나 글 주소 중 하나는 필요합니다. 주소는 cafe.naver.com/카페명/글번호 형태의 일부만 입력해도 됩니다.

순위표

검색 범위는 각 채널 50위까지입니다. 매일 오전 9시(KST) 이후 서버가 자동으로 확인합니다. 조회가 막히면 -로 표시됩니다.

데이터 백업

프로젝트와 순위 기록 전체가 한 파일로 저장됩니다. 복원하면 현재 데이터가 파일 내용으로 바뀝니다(바꾸기 전 파일은 서버에 따로 보관).
