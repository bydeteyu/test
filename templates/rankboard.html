키워드로 순위 검색

한 줄에 하나씩 또는 콤마(,)로 구분 — 통합검색과 카페탭을 각각 30위까지 수집하고 오늘 날짜로 기록합니다. 검색한 키워드는 매일 오전 9시 30분에 자동으로 다시 기록됩니다.

검색 결과 · 기록

초록색 행은 아래에 등록한 추적 콘텐츠입니다. CSV에는 선택한 키워드의 전체 날짜 기록이 들어갑니다.

추적 콘텐츠 순위표

내 글이 통합검색·카페탭에서 몇 위인지 날짜별로 기록합니다. 제목에 들어간 문구나 글 주소 중 하나만 입력해도 됩니다.

검색 범위는 통합·카페탭 각각 20위까지이며, 범위 밖이면 "20위 밖"으로 표시됩니다. 조회가 실패한 칸은 "-"로 표시합니다. 데이터 보존에는 DATA_DIR(Volume) 설정이 필요합니다.
