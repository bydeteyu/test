순위 체크 (Threads)

게시글 링크를 등록하면 매일 조회수를 기록합니다. 연결한 계정의 글은 Meta 공식 API로, 그 밖의 글은 공개 페이지의 조회수를 읽습니다.

처음 한 번: Meta 개발자 앱 연결 준비

서버에 THREADS_APP_ID, THREADS_APP_SECRET 환경 변수가 아직 없습니다. 아래 순서대로 준비한 뒤 설정하세요.

  2. Threads 설정에서 리디렉션 콜백 URL에 아래 주소를 등록합니다:
  3. 권한 threads_basic, threads_manage_insights를 사용 설정합니다.
  4. 앱 역할에서 연결할 Threads 계정을 Threads 테스터로 추가하고, 그 계정에서 초대를 수락합니다.

프로젝트

연결된 Threads 계정

토큰은 Meta 개발자 앱 → 이용 사례 → Threads API → 설정 → 사용자 토큰 생성기에서 연결할 계정(Threads 테스터)을 선택해 만듭니다. 장기 토큰(약 60일)이며 서버가 만료 전에 자동으로 갱신합니다. 토큰은 화면에 다시 표시되지 않습니다.

좋아요·댓글 수집: Chrome 확장 프로그램

공개 링크 글은 서버가 조회수만 읽을 수 있습니다. 담당자 PC의 로그인된 Chrome에 확장 프로그램을 설치하면, 매일 등록된 글을 열어 조회수·좋아요·댓글을 읽어 이 화면에 기록합니다. (PC가 켜져 있고 Chrome이 열려 있어야 합니다)
  1. 확장 프로그램 내려받기(zip) 후 압축을 풉니다.
  2. Chrome 주소창에 chrome://extensions → 오른쪽 위 개발자 모드 켜기 → 압축해제된 확장 프로그램을 로드합니다 → 압축 푼 threads-extension 폴더 선택.
  3. 확장 프로그램의 설정에서 서버 주소 와 아래 키를 붙여넣고 저장합니다. 이 Chrome에서 Threads에 로그인해 두세요.
키는 이 서버에 글 숫자를 보내는 용도로만 쓰입니다. 유출되면 "키 다시 만들기"로 바꾸세요(기존 확장 프로그램은 새 키로 다시 설정해야 합니다).

추적할 게시글 추가

주소는 게시글의 공유 버튼 → 링크 복사로 얻습니다. 연결한 계정의 글이면 공식 API로 조회수·좋아요·댓글을 기록하고, 그 밖의 글(의뢰한 외부 계정 등)은 공개 링크로 등록되어 매일 공개 페이지에 보이는 조회수를 읽어 기록합니다.

조회수 현황

매일 오전 9시(KST) 이후 서버가 등록된 모든 게시글을 자동으로 기록합니다. "전체조회"는 체크한 게시글만 지금 바로 조회합니다. 조회수 증감은 직전 기록 대비입니다.
