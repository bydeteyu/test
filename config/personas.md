# 타깃 페르소나

## 페르소나 A — "검진 충격 주부" (40-50대 여성)

- **연령**: 43-55세
- **직업**: 전업주부 / 파트타임 직장인
- **계기**: 건강검진에서 공복혈당 108-125 or 혈압 135/85 이상 경계 수치
- **심리**: "아직 약 먹을 정도는 아니래는데 불안하다" / "남편·아이들 챙기다 내 몸 놓쳤다"
- **행동 패턴**: 네이버 카페(맘카페, 건강카페) 검색 → 후기 글 읽음 → 공감 댓글 달기
- **커뮤니케이션**: "저도요ㅠㅠ", "어디서 구매하셨어요?", "OO씨 후기 들었어요"
- **금지 접근**: 의학 전문 용어 나열, 무서운 질병 직접 언급
- **효과적 접근**: 일상 공감 → 수치 → 자연스러운 해결책 탐색

## 페르소나 B — "회식 잦은 직장인 남성" (50-60대 남성)

- **연령**: 48-62세
- **직업**: 중간관리자, 자영업자
- **계기**: 회사 건강검진 LDL 170+ / 혈압 140+ / 스타틴 처방 받았는데 근육통
- **심리**: "약은 되도록 안 먹고 싶다" / "운동은 힘들고 뭔가 편하게 관리하고 싶다"
- **행동 패턴**: 네이버 블로그 검색 → 정보성 글 → 유튜브 영상
- **커뮤니케이션**: 간결한 정보, 수치 근거, "효과 있으셨나요?"
- **금지 접근**: 감성적 공감 과도, 너무 복잡한 설명
- **효과적 접근**: 수치 + 원인 + 자연 대안 흐름

---

## 페르소나 C — "혈당 스파이크 인식 MZ" (30-40대 여성)

- **연령**: 32-42세
- **직업**: 직장인, 자영업
- **계기**: SNS에서 혈당 스파이크 콘텐츠 접함 → 자가 측정 → 식후 160-190 확인
- **심리**: "당뇨는 아닌데 혈당 스파이크 관리하고 싶다" / "먹고 싶은 거 못 참겠다"
- **행동 패턴**: 인스타·유튜브 → 네이버 블로그 검색 → 커뮤니티 후기
- **커뮤니케이션**: 트렌디, 구체 수치, 음식 이야기, 솔직한 후기 톤
- **금지 접근**: 올드한 표현, 약 이야기
- **효과적 접근**: "이거 먹으면 라면 먹어도 될까요?" 식의 현실적 궁금증
