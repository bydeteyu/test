# 네이버 카페글 수집기 — 웹 어드민

## 설치

```bash
pip install -r requirements.txt
playwright install chromium
```

## 실행

```bash
python app.py
```

브라우저에서 http://localhost:5000 접속

## 사용법

1. 검색 키워드를 한 줄에 하나씩 (또는 콤마로 구분) 입력
2. **검색 시작** 클릭
3. 수집 완료 후 결과 테이블 확인
4. **엑셀 다운로드** 버튼으로 CSV 저장

> `output/` 폴더에 키워드별 CSV 파일이 저장됩니다.

## 순위 기록 (`/rankboard`)

키워드를 검색하면 **통합검색**과 **카페탭**을 각각 상위 30위까지 수집해 날짜별로 기록합니다. 기존 `/rank`(검색 순위), 카페글 노출 알림과는 별개입니다.

- **키워드 검색**: 여러 키워드를 입력하고 "순위 확인 시작". 결과는 키워드·날짜·채널별로 조회하고 CSV로 내려받을 수 있습니다. 같은 날 다시 검색하면 그날 기록을 덮어씁니다.
- **추적 콘텐츠**: 키워드 + (제목에 포함된 문구 또는 글 주소)를 등록하면 통합·카페탭 20위 안의 순위를 날짜별 표(최근 7일)로 보여줍니다. 범위 밖은 "20위 밖", 조회 실패는 "-"입니다.
- **순위 기준**: 통합검색은 블로그·카페 게시글이 화면에 나오는 순서, 카페탭은 카페 글만의 순서입니다. 같은 글의 중복 링크(썸네일·댓글 미리보기)는 한 번만 셉니다.
- **자동 실행**: 매일 오전 9시 30분(KST)에 추적 콘텐츠와 검색해 둔 키워드를 다시 확인해 기록합니다. 브라우저 실행은 카페글 노출 알림과 같은 락을 써서 동시에 뜨지 않습니다.
- 데이터는 `DATA_DIR/rank_history.json`에 저장됩니다(다른 데이터와 마찬가지로 Railway에서는 Volume 필요).
- 테스트: `python -m unittest discover -s tests`
